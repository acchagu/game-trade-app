ゲームソフト売買表 Ver.1.1

index.html をダブルクリックして起動できます。

機能:
・ゲームタイトル
・機種 PS / Switch / その他
・購入日 / 購入価格
・購入場所 ゲオ / Amazon / オンライン / DLC / その他
・売却日 / 売却価格
・売却場所 ゲオ / その他
・売却総額の自動計算
・1本ごとの実質負担額
・今年の購入総額 / 売却総額 / 実質支出
・記録一覧 / 削除

データはブラウザのlocalStorageに保存されます。

・買取アップは1本ごとではなく「まとめ売りボーナス」として別記録
・まとめ売りボーナス：売却日 / 売却場所 / 対象ゲーム / ボーナス総額
・今年の売却総額には各ゲームの売却価格＋まとめ売りボーナスを合算
・各ゲームの実質負担額にはまとめ売りボーナスは割り振らない
